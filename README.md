Overview

FlightTrack is a data analytics project designed to help airport authorities and operations teams analyze flight delay patterns. 
Using PySpark, Azure SQL, and Power BI, this project processes and visualizes flight data to uncover trends such as peak delay periods, major causes of delays, and airline or route-specific bottlenecks.

Project Objectives

Ingest and process real-world or simulated flight delay datasets.

Perform data cleaning, categorization, and aggregation using PySpark.

Store the transformed data in Azure SQL Database.

Build an interactive Power BI dashboard for delay insights and reports.
